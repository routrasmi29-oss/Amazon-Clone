# 🛒 Amazon Clone – E-Commerce Web Application

## 📌 Project Overview

Amazon Clone is a full-stack e-commerce web application developed using Python and Django. It provides an online shopping experience where users can browse products, search items, add products to their cart, place orders, and manage their profiles.

This project was developed to demonstrate practical knowledge of web development, backend programming, database management, and e-commerce functionality.

## 🚀 Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** SQLite3
- **Tools:** Visual Studio Code, Git, GitHub
- **Payment Integration:** Razorpay

## ✨ Key Features

### 👤 User Management
- User Registration and Login

### 🛍️ Shopping Features

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/routrasmi29-oss/Amazon-Clone.git
```

### 2. Open Project Directory

```bash
cd Amazon-Clone
```

### 3. Create Virtual Environment

```bash
python -m venv myenv
```

### 4. Activate Virtual Environment

```bash
myenv\Scripts\activate
```

### 5. Install Django

```bash
pip install django
```

Install other required dependencies from requirements.txt if provided.

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Run Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

http://127.0.0.1:8000/
